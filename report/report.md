## Method

We solve the double-precision five-point Jacobi stencil on a global 2-D grid with fixed zero boundaries. Each update is the average of the north, south, west, and east neighbours. The solver stores separate old and new grids and initializes interior values deterministically.

## Dataset

The input is explicitly **SYNTHETIC**, generated by `dataset/generate_dataset.py`: two deterministic Gaussian hot spots in arbitrary temperature units with zero values on all four physical boundaries. CSV input is loaded only by rank 0, validated, and distributed as owned strips or Cartesian blocks. It is not claimed to be real-world temperature data.

Two decompositions are compared. The 1-D version assigns horizontal strips and exchanges halo rows. The 2-D version uses `MPI_Dims_create`, `MPI_Cart_create`, and `MPI_Cart_shift` to construct a Cartesian grid and discover north, south, east, and west neighbours. Row halos are contiguous; column halos use `MPI_Type_vector` with the padded local row pitch.

Blocking mode completes `MPI_Sendrecv` halo exchanges before calculation. Overlap mode posts `MPI_Irecv` and `MPI_Isend`, calculates halo-independent interior cells, calls `MPI_Waitall`, then calculates edge cells. The residual is the maximum absolute update and is combined using `MPI_Allreduce(MPI_MAX)`. Runs support fixed iterations so residual-check intervals do not alter the amount of work.
